## 精妙整理

使精妙核心自带的整理功能可以作用于玩家物品栏和更多普通容器，让常用界面里的整理方式尽量统一。

本模组本身并不重新实现一套新的整理系统，而是把精妙核心已有的整理入口扩展到更多界面中。

### 主要功能

#### 整理按钮扩展

本模组会在大部分普通容器界面中补上精妙核心原本的整理按钮。

这里的“扩展”指的是把精妙核心的整理入口带到更多非精妙系列容器里，而不是额外加入另一套完全不同的整理逻辑。

整理时仍然使用精妙核心原本的四种整理模式：

- 按名称
- 按模组
- 按数量
- 按标签

默认模式为按名称。

一个按钮用于执行整理，另一个按钮用于切换整理模式。已经习惯精妙系列整理方式的玩家，基本不需要重新适应。

#### 玩家物品栏整理

本模组可以整理玩家自己的物品栏。

当当前界面不满足“整理容器本身”的条件时，模组会改为整理玩家物品栏。因此即使打开的是工作台、熔炉、配方类界面，依然可以快速整理自己身上的物品。

当当前界面满足条件时，本模组会整理当前容器本身，而不是整理玩家物品栏。

这样在箱子、木桶之类的普通容器中，也可以使用和精妙核心风格一致的整理方式。

即使某些界面中不显示整理按钮，仍然可以使用快捷键整理。

默认快捷键为 `R`。

快捷键和按钮使用同一套目标判断逻辑：如果当前界面适合整理容器，就整理容器；否则整理玩家物品栏。

### 容器筛选规则

本模组的“是否整理当前容器”由两项筛选共同控制：

配置项：`Filter1`，默认开启。  
开启后，只有总槽位数大于 `46` 的界面才会被视为可整理容器本身；否则会改为整理玩家物品栏。  
这里的46可以理解为玩家物品栏36 + 普通小容器10。  
所以像工作台、一些小型功能界面这类总槽位数不大的界面，默认不会整理容器本身。

配置项：`Filter2`，默认开启。  
开启后，只要当前界面里存在明显不适合参与整理的槽位，模组就不会把这个界面当作“可整理容器”。  
最典型的例子就是合成结果槽这类特殊槽位。  
这项筛选的作用是尽量减少在功能型界面里误整理到特殊槽位的情况。

对于普通容器界面，只有在它满足当前筛选条件、并且没有被加入黑名单时，才会显示整理按钮。  
如果一个界面不适合整理容器本身，那么按钮通常不会显示，但此时仍然可以通过快捷键整理玩家物品栏。

### 与精妙系列容器的关系

精妙系列自己的容器仍然使用精妙核心原本的整理入口和整理逻辑。

本模组不会在这些界面上再额外补一套按钮，也不会替换它们原本的整理实现。

这样做是为了保证堆叠升级、槽位规则以及精妙系列自身的容器机制能够正常工作。

换句话说，本模组扩展的是“更多普通容器能方便地调用整理”，而不是接管精妙系列容器原本的整理功能。

### 黑名单

如果某个界面不希望显示本模组添加的按钮，可以把它加入黑名单。

在目标界面中按下 `U`，即可将当前界面加入或移出黑名单。

黑名单配置项为 `specialList`。

其中保存的通常是当前界面标题对应的翻译键，而不是界面上直接显示出来的文字。

常见示例：

- `container.chest`
- `container.barrel`
- `container.enderchest`

如果你不确定某个界面该填写什么，最简单的方式通常不是手动改配置，而是直接打开该界面按一次 `U`。

### 拼音排序

配置项：`pinyin`

默认开启。

开启后，在中文环境下会启用默认拼音排序；关闭后则不启用这项处理。

### 模组定位

本模组只是将精妙核心的整理功能扩展到更多界面中，自身并不打算发展成一套独立的大型仓储系统。

因此它更偏向于：

- 补齐体验
- 统一操作
- 减少来回切换

而不会刻意加入过多与“整理入口扩展”无关的复杂功能。
