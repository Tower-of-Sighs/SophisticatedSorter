# Minecraft 26.1 Targets

The NeoForge 26.1 target uses Java 25 and the official Minecraft namespace
exposed by the current NeoForge toolchain. It is a separate Gradle project and
must be built with its own wrapper.

## NeoForge

`neoforge-26.1` consumes SophisticatedCore `26.1-1.4.27.1690` from the
target's `libs/` directory. This version is not available from Modrinth's
Maven endpoint, so the jar must be provided as a local target dependency.

The 1.21.1 Minecraft adapter sources are not compiled for this target because
26.1 changed the identifier, inventory, key mapping, and packet APIs. The
target-local bridge keeps player inventory and ordinary container sorting
available while SophisticatedCore retains ownership of its own storage GUI.
Published SophisticatedBackpacks 26.1 files currently reference the removed
`BlockEvent.BreakEvent` API and are therefore intentionally not included in
the dev runtime until an upstream-compatible release is available.
